# Two-Stage-Deep-Learning-for-Solar-Panel-Detection-UNet-Segmentation-with-CNN-Classification-
Presenting a cascaded deep learning pipeline for solar panel detection combining UNet++ segmentation (EfficientNet-B7 encoder) with EfficientNet-B0 classification. Stage 1 achieves 95% recall; Stage 2 reduces false positives by 33% while maintaining 92% recall.
